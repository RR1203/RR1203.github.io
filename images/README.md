# images

Photos and graphics used on the website live in this folder.

## How to add a picture

1. Open this folder on GitHub, click **Add file** then **Upload files**.
2. Drag the picture in and commit.
3. Tell Claude the filename and which section it belongs to.

## Naming

- lowercase only, words joined by hyphens, no spaces, no umlauts
- pattern: `section-subject.ext`
- example: `growing-up-pokemon-ruby.jpg`
- cut-outs with a transparent background: PNG, filename ends in `-cut`
- example: `growing-up-mario-disc-cut.png`

## Format and size

- JPG for photographs, PNG only when transparency is needed, SVG for drawings
- longest edge 1600 px is plenty
- keep each file below roughly 400 KB so the site stays fast

## Rights

Only upload pictures you took yourself or otherwise own. The site deliberately
makes no third-party requests, so every image has to be stored in this repository.
