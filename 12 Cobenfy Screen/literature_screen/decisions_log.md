# Decisions log

1. **Location.** `12 Cobenfy Screen/` did not exist, so I created it at the repo root (`RR1203.github.io`). Work is committed on branch `claude/vibrant-johnson-iqp0nc`, not the default branch, so it is not published on the website.
2. **Network.** PubMed, Europe PMC, Open Targets and the GWAS Catalog were blocked by the environment's network policy. I added `eutils.ncbi.nlm.nih.gov`, `pubmed.ncbi.nlm.nih.gov`, `www.ebi.ac.uk` and `api.platform.opentargets.org` to the environment allowlist. ClinicalTrials.gov was already allowed. The PubMed/Clinical_Trials MCP connectors failed to connect, so I used the REST APIs directly.
3. **Retrieval depth.** For each condition × evidence-type query I took the top **6 abstracts by PubMed relevance**; for the antipsychotic-response query, the top 4. This keeps the run tractable (983 abstracts). The trade-off: evidence types with many papers are under-sampled, and the total hit count is logged so this is visible.
4. **Extraction.** The LLM read every abstract in full and coded direction, type, design, n and finding. Eight parallel subagents shared one instruction file (`extraction/INSTRUCTIONS.md`). Full-text OA was not fetched; abstracts only.
5. **Batch 2 not extracted (major gap).** One batch (109 abstracts, 123 pairs) was stopped twice by an automated safety filter: once in a subagent, once when I coded it myself. It was dominated by chronic pain (44 pairs), cocaine (38), delirium (13), COPD (11), chemo-brain (3) and methamphetamine (3). I did not try to work around the filter. Those conditions therefore score low **for lack of extraction, not lack of evidence**; they are marked `*` in the figure. Before the stop I had read several relevant abstracts, now left for manual review, including xanomeline analgesia in rodent chronic-pain models (PMID 22018972) and a donepezil RCT for post-chemotherapy cognition (PMID 26130292, n=62). These are **not scored**.
6. **Direction convention.** "Helps" means more cholinergic/M1/M4 signalling improves the condition, or less signalling (anticholinergic burden, scopolamine, receptor loss) worsens it. "Harms" is the reverse, including "anticholinergics treat it".
7. **Scoring v1** (as specified). Per condition × type, the type counts if "helps" items outnumber "harms" items. Weights: human type = 2, animal = 1, and animal counts only if some human type points the same way. The weight is halved if opposing plus null items ≥ supporting items (contradictory), and halved again if all supporting human items are n<20 and not RCT/meta/cohort/postmortem/PET (tiny).
8. **Positive-control failure and fix.**
   - Under v1, AD cognition ranked 1 and AD psychosis 3, but **bipolar mania scored 1.0 (rank 22/39). This fails.**
   - Diagnosis: the screen measured only "cholinergic deficit" evidence. Cobenfy's proven effect, and the rationale for the mania trials, is **antipsychotic**: M4-mediated reduction of striatal dopamine. Also, ChEI nulls (ChEIs are not M1/M4 agonists) were counting fully against.
   - Fix (v2): (a) added evidence type **0_antipsychotic_response**, a human RCT/meta-analysis showing D2-blocking antipsychotics improve the condition, coded by a subagent from 114 newly retrieved abstracts; (b) a null now counts half against.
   - Result: bipolar mania rose to 4.0 (rank 12/39), AD psychosis to rank 1, AD cognition to rank 4. Bipolar mania is upper-third but not top-5. I accepted this rather than tuning further, to avoid overfitting to the controls.
9. **v3 restriction of type 0 (from the spot check).** Antipsychotic benefit counts only in dopamine-hyperactivity syndromes: psychoses, mania, tics, chorea, irritability/agitation, delirium, OCD augmentation and tardive syndromes. Elsewhere (sleep, migraine, gastroparesis, depression, PTSD, anxiety, borderline, ADHD-in-autism) the antipsychotic effect is plausibly H1, 5-HT2A or chemoreceptor-trigger-zone mediated, so those rows were set to "unclear".
10. **Spot-check corrections** (`extraction/spotcheck_overrides.json`):
    - PMID 36463762 (quetiapine for sleep): helps → unclear. The effect is H1-mediated.
    - PMID 24494624 (scopolamine abuse toxidrome counted as sleep evidence): helps → unclear.
    - The other 13 of 15 re-read abstracts were coded correctly. One minor note: PMID 26287759 is a mixed brain/spinal-injury cohort, not TBI-only. Kept, but noted.
11. **Clinical status** was assigned by hand from ClinicalTrials.gov NCT records (trials.csv) and Europe PMC title searches. Case reports do not count as "tested". Epilepsy has two Cobenfy studies, but they are mechanistic memory studies, so it is labelled "in trials (memory, not seizures)".
12. **Peripheral conditions.** Sjögren's/xerostomia and gastroparesis were excluded from the candidate list because they depend on peripheral M3 effects, which trospium blocks by design.
13. **Genetics.** Open Targets (CHRM1–5) and GWAS Catalog associations were downloaded (`raw/opentargets.json`, `raw/gwas_catalog.json`).
    - **CHRM4** has Open Targets genetic-association scores of 0.28–0.46 for schizophrenia, autism, bipolar disorder, MDD, ADHD, OCD and anorexia nervosa. The near-identical scores suggest one shared cross-psychiatric locus on chr11p11, a high-LD region (cf. PMID 27269905). The signal is non-directional and not M4-specific.
    - **CHRM1:** insomnia only (0.10; also GWAS Catalog).
    - These signals were **not scored**, because direction (helps vs harms) cannot be assigned. Sensitivity check: counting them as a human type would add 2 points to bipolar mania (to 6.0), autism, ADHD, OCD, anorexia and MDD. It would not change the top 3 untested candidates.
    - Only the 28 directional genetic abstracts were scored. No CHRM1/CHRM4 drug-target Mendelian randomization paper was retrieved.
14. **Press releases.** One web search was run. It confirmed the AD psychosis/agitation, bipolar and autism programmes at secondary-source level; ClinicalTrials.gov was used as the primary source.
15. **Negative controls.** Psoriasis, hypothyroidism and gout all scored 0 for benefit. Psoriasis scored 1.0 for harm, from small scopolamine pilot studies (PMID 33570237, PMID 42742566). This is a real peripheral anticholinergic effect, not an artefact, and is reported but not ranked.
