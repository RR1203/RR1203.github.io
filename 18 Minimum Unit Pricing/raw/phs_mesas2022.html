Published
21 June 2022
Type

Description

The Monitoring and Evaluating Scotland's Alcohol Strategy (MESAS) monitoring report 2022 presents all the latest available data on key alcohol indicators in Scotland. Supporting data sets and charts can be found in the workbooks below.
